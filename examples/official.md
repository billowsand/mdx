# 公文转换示例

这是一份用于快速体验 `official` 样式的最小文档。标题中的编号由 mdx 自动生成，无需手写。

## 总体要求

正文会使用公文排版所需的字体、字号、段落与页边距。你可以在段落中使用**加粗**、*强调*、`行内代码`和[普通链接](https://example.org)。

- 完成材料收集
- 完成内容复核

#### 注意事项

| 项目 | 要求 |
|---|---|
| 文件格式 | Markdown |
| 输出格式 | DOCX 或 TeX/PDF |
