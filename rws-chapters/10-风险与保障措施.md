## 第十章 风险与保障措施

| 风险 | 主要表现 | 预防与应对 |
|---|---|---|
| 理论与系统脱节 | 理论成果无法转换为算法输入和验收指标 | 理论课题同步提交要素、规则、指标、样例和技术转化说明 |
| 大模型幻觉 | 结论、法理、口径或方案无依据 | 证据绑定、冲突提示、人工审核、低置信度标识和基准测试 |
| 提示词注入 | 外部内容或工作流诱导越权 | 输入检测、工具白名单、权限隔离、工作流审核和审计 |
| 数据质量不足 | 缺失、错误、偏差影响结论 | 数据质量规则、来源分级、缺失标识、人工复核和质量报告 |
| 虚假信息错误定性 | 将证据不足或观点表达错误认定为虚假信息，造成处置失当 | 疑似状态管理、多源核验、事实与观点区分、证据等级、人工审定和结论撤销机制 |
| 对手意图误判 | 以单一线索推断对手目的，忽视替代解释和反对证据 | 竞争性假设、支撑与反对证据对照、信息缺口管理、动态更新和专家复核 |
| 知识错误扩散 | 错误页面影响多次研究 | 入库审核、冲突候选、版本回滚、定期审计和来源追溯 |
| 推演偏离执行问题 | 将推演用于效果预测，未能发现实际执行中的组织、资源、任务和时序问题 | 固化可执行性推演边界，使用真实组织职责、资源能力、审批规则和任务依赖，开展预置缺陷检出和调整后回放 |
| 组织协调失灵 | 牵头配合不清、审批断点或跨部门接口不闭合 | 责任矩阵、审批链检查、协调节点、超时升级、过程留痕和事后复盘 |
| 资源与时序冲突 | 关键资源重复占用、前置任务延误或时间窗口相互挤压 | 资源负荷分析、关键路径、时间窗口检查、替代资源和备用路径 |
| 叙事冲突 | 不同产品、渠道或阶段的事实表述、立场和行动信号相互矛盾 | 统一事实基线和口径版本，设置叙事约束，开展跨产品一致性检查和发布前审定 |
| 评价失真 | 指标缺数据或责任不清 | 指标数据责任清单、计算口径、基线固化和独立验证 |
| 需求扩张 | 任务书边界不断扩大 | 需求、设计、交付三类基线和正式变更评估审批 |
| 外部平台限制 | 采集限流、封禁或数据缺失 | 合规采集、来源替代、数据完整性标识和人工处置 |
| 关键能力绑定 | 厂商或组件形成锁定 | 标准接口、可替换架构、完整源代码和依赖清单交付 |
| 对手战术演化 | 对手手法更新导致既有识别规则失效 | 跟踪公开威胁研究，持续更新对手战术手法库，将手法识别纳入核验规则迭代 |
